# Project artwork

These assets are copied unchanged from the projects' existing branding:

- `powertools-lambda-go.png`: `powertools-lambda-go/docs/favicon.png` in the local
  `aws-lambda-go-powertools` workspace; the project's ram/cloud/Go Gopher emblem.
  Source project: https://github.com/rambow-cloud/powertools-lambda-go.
- `drawio-software-icons.svg`: `src/favicon.svg` from the local
  `drawio-software-icons` repository; its ram/cloud/icon-tile emblem.
  Source project: https://github.com/rambow-cloud/drawio-software-icons.

The Go Gopher was created by Renee French and is licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
The Powertools project adapts it into its ram/cloud branding; this website copies
the published artwork without further modification. See the project's
`website/BRANDING.md` and `THIRD_PARTY_NOTICES.md`, and
[Go's Gopher attribution](https://go.dev/blog/gopher).

Alibaba Cloud SDK for Go currently has no independent image asset in its local
repository. Its card uses the existing Rambow Cloud organization emblem from
`public/branding/` as a fallback, rather than an Alibaba Cloud vendor logo.

Preserve colors, transparency, and proportions. Project assets remain separate
from the organization logo, and all website paths must respect Astro's base URL.
